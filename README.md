# Ashfaque Chowdhury · Portfolio

A modern, interactive portfolio website built with Vue 3, Three.js, and Vite.

## Features
- 🎨 Glassmorphism UI design
- ✨ 3D particle animation background (Three.js)
- 📝 Editable JSON data file (`src/data/portfolio.json`)
- 🚀 Fast development with Vite
- 📱 Fully responsive

## Setup

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
